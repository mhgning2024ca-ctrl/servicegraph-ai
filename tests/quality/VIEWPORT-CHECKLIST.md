# ServiceGraph AI viewport smoke checklist

Record browser, commit and result. A checked box is manual evidence, not an automated claim.

## Citizen — 390 × 844

- [ ] FR | EN selector is visible, keyboard reachable and persists after refresh.
- [ ] Status, report form, queued/sent/correlated/resolved states fit without horizontal scroll.
- [ ] Text submission and validation are readable at 200% zoom.
- [ ] Voice failure visibly falls back to text; no fake transcript appears.
- [ ] Offline report is queued and retry state is distinguishable.
- [ ] PWA manifest/install path is available.

## NOC — 1440 × 900

- [ ] Health, incident queue, topology and causal graph retain operational hierarchy.
- [ ] Incident evidence, confidence, blast radius and provider degradation are visible.
- [ ] Unauthorized users cannot approve; hiding a control is not counted as server authorization.
- [ ] Approval, remediation, verification and communication states are distinct.
- [ ] FR and EN contain no accidental mixed-language product copy.

## Tablet — 768 × 1024

- [ ] NOC remains usable without clipped primary actions.
- [ ] Causal graph can be inspected by keyboard/touch.
- [ ] Focus indicators and reduced-motion behavior are preserved.
